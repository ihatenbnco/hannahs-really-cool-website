Run a snowflake node

Snowflake is a volunteer-run network of inderpendant 'snowflakes' that allow people in censored countries to freely access the internet, and it is easy to run your own snowflake, just click the start snowflake buttong and keep that tab open. It consumed minimal bandwidth and has no legal risk asociated with it. Warning: It needs JavaScrit enabled to load, and will use JavaScript from https://snowflake.torproject.org/. It is the only part of this website that is not compatible with lynx and without JS, Tor doesn't offer a no-JS way to embed a snowflake in a website

If you could, it does helo out people trying to access the internet from countries like China or Iran, so if you can, it would be cool of you to leave this tab open with your Snowflake running <3. You can also visit The dedicated Snowflake page for convinience, if you wish.
